# 과제 10 제출 준비 상태

**상태: 최종 논문 PDF 누락으로 제출 준비 미완료. 최종 ZIP은 생성하지 않았습니다.**

## 이번 정리에서 실제 확인한 사항

| 검증 | 결과 |
|---|---|
| 기존 프로젝트 파일 보존 | 원 프로젝트 161개 파일의 복사본과 원본 SHA256 일치 |
| 전체 원자료 | UniProt 릴리스 2026_03, JSON 41페이지·TSV 41페이지, 수집 상태 complete |
| 수집 원본 체크섬 | raw_inventory에 있는 응답 93개 파일 확인 |
| 소량 검증 원본 | 기존 메타데이터에 기록된 응답 체크섬 일치 |
| 분석 입력 | CSV 20,431행, accession 20,431개, 기존 SHA256 일치 |
| 오프라인 전처리 재실행 | 분석 CSV·품질 보고서·데이터 메타데이터 3개가 기존 결과와 바이트 단위 일치 |
| 통계 분석 재실행 | 기술통계·상관·민감도·선택 이력·bootstrap CSV 5개가 기존 결과와 바이트 단위 일치 |
| 통계 방법 | seed 20261030, 각 결과별 bootstrap 2,000회, 동률 재순위화와 양측 p 유지 |
| 주요 상관 | rho 0.27045797006849343, n=20,431 |
| GO 0개 제외 | rho 0.23311079545325067, n=19,375 |
| 유전자 기준 민감도 | rho 0.20132928681391218, n=19,031 |

| 테스트 | 실제 11개 실행, 전부 통과. API 요청은 모의 응답 사용 |
| 외부 API 재수집 | 수행하지 않음 |
| 기존 원본·검증 결과 수정 | 하지 않음 |
| Git commit/push | 하지 않음 |

증거: `verification_run/reproducibility_report.json` 및 `verification_run/logs/`.
초기 제한 환경에서는 테스트용 임시 디렉터리 권한 때문에 2개가 오류를 냈습니다. `tests_initial_sandbox_failure.log`에 보존했고, 권한을 받은 재실행에서 11개 통과를 확인했습니다. 실패 로그를 통과 결과로 바꾸어 해석하지 않았습니다.

## 포함 파일과 별도 기록

실제 파일의 전체 상대경로 목록과 SHA256은 `checksums.sha256`에 있습니다. 원래 프로젝트 파일의 원본→제출 위치 매핑은 `provenance/source_inventory.json`에 있습니다. 실행 코드, 원자료, 분석 데이터, 품질·통계 결과, 그림, 테스트와 로그를 포함합니다. Python 실행 파일·가상환경은 복사하지 않았습니다. `runtime_cache`는 실행 중 생성된 작업용 캐시로 체크섬 및 최종 압축 대상에서 제외합니다.

## 누락 및 최종 ZIP 생성 전 필요한 작업

1. `paper/`에 **연구자가 검토한 최종 논문 PDF**를 추가해야 합니다. 현재 `paper/README.md`만 있으며 빈 PDF·임시 논문은 없습니다.
2. 최종 PDF의 내용·수치·참고문헌과 열림 상태를 확인해야 합니다. 개별 그래프 PDF가 논문 PDF를 대신하지 않습니다.
3. 예상한 변경인지 확인한 뒤 `05_verify_submission.py --compare-rerun`, `--write-manifest`, `--verify-checksums`를 차례로 실행합니다.
4. 실행 환경·캐시를 제외하고 제출 폴더 전체를 ZIP 1개로 만들고, 별도 위치에 풀어 체크섬과 논문·원자료·안내 문서의 열림 상태를 확인해야 합니다.

이번에는 이미 설치된 원 프로젝트의 Python 환경으로 검증했습니다. 새 환경 설치, 다른 운영체제 실행, 최종 논문 PDF 검토와 최종 ZIP 압축·해제 검증은 수행하지 않았습니다. 연구자의 별도 수작업 검증이 수행됐다고 임의로 기록하지 않았습니다.
